# Як тут працюють

Єдиний дозволений спосіб роботи — вайбкодити і слопати.

Pull request, зібраний обережним ручним інжинірингом поза цим стилем, сюди не беремо. Пиши по відчуттю і віддавай наступну іграбельну зміну. Без вилизування, ревʼю архітектури і обережного продакшн-проходу.

English: the only allowed way to work is vibe-coding and slopping. Careful hand-engineering pull requests are out of scope.
