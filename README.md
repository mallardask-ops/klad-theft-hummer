# Великий Кладій Закладок

Перший ігровий епізод на Godot 4.7.2. Подро повернувся в місто. Едік просить доставити каву, чужа коробка витягує борги, а молоток стає способом домовитися. Чотири послідовні місії з доставки, розмов, підбору предметів, боїв і втечі.

## Запуск

Linux x86_64: запусти `builds/KladTheftHummer.x86_64`, у меню обери «НОВА ГРА» або «ПРОДОВЖИТИ». Godot для цього не потрібен. Для редагування відкрий `project.godot` у Godot 4.7.x.

```sh
./builds/KladTheftHummer.x86_64
```

Вихідний проєкт:

```sh
godot --path .
```

## Керування

| Дія | Клавіші |
| --- | --- |
| Рух / їзда | WASD або стрілки |
| Камера | Миша, правий стік геймпада |
| Біг | Shift |
| Стрибок / ручне гальмо | Space |
| Сісти / вийти з машини | F |
| Розмова / забрати предмет | E або Enter |
| Молоток | ЛКМ або Ctrl |
| Карта міста | M або Tab |
| Пауза | Esc |
| Радіо в машині | R |
| Дальність камери | V |

Машину потрібно загальмувати перед виходом. Предмети збираються пішки. Жовта точка на радарі й велика карта ведуть до цілі. Розшук спадає, коли патруль не бачить Подро. Остання місія закінчується тільки у схованці без розшуку. Пауза дозволяє повторити поточну місію; винагороди завершених місій зберігаються.

Геймпад: лівий стік рух, правий камера, A стрибок/гальмо, Y машина, X дія, RB молоток, LB біг, Start пауза, Back карта. Меню: стрілки або Tab/Shift+Tab, Enter; миша теж працює.

Налаштування: радіо, тряска камери, чутливість миші, загальна гучність. Прогрес автоматично записується після місії. «ПРОДОВЖИТИ» відновлює останній завершений етап, а не позицію посеред місії. Збереження та налаштування лежать у стандартному Godot `user://`.

## Що є в епізоді

- Відкрита стилізована карта приблизно 480×480 м: площа, панельки, базар, кафе, гаражі, лісопилка, гранітний кар'єр, Тетерів.
- Керований Подро, молоток, ходьба, біг, стрибки й атаки з Blender-анімаціями.
- Жигулі, маршрутки, міліцейські машини, дорожній рух, пішоходи, наїздники й патрулі.
- Чотири місії, розшук, гроші, винагороди, смерть/знищення/падіння у воду та швидкий повтор.
- HUD у прямо замовленому стилі GTA III: годинник, гроші, здоров'я, зброя, зірки, круглий радар, назви районів, субтитри й результати місій.
- 31 аудіоасет: записані кроки, удари, машини, сирена й середовище; готовий фанк-трек для радіо. Двигуни мають окремі шари холостого ходу та газу, а звуки світу — просторове відтворення.
- 11 оригінальних GLB, редаговані Blender-файли, маленькі текстури та шрифти з кирилицею.

Це перший завершений епізод. Карта є художньою версією Коростишева. Інтер'єри, озвучка, стрілецька зброя та решта довгої кампанії описані як наступний обсяг у `docs/campaign.md`; вони не входять до цього білда.

## Перевірки

Результати та межі доказів: `docs/qa-report.md`. Raw logs і знімки: `artifacts/validation/`.

```sh
godot --headless --path . --quit-after 120
godot --path . -- --verify --evidence-dir=/tmp/kth-replay
XDG_DATA_HOME=/tmp/kth-qa godot --headless --path . --script res://tools/edge_cases.gd
godot --path . --script res://tools/driving_replay.gd
godot --headless --path . --export-release Linux builds/KladTheftHummer.x86_64
```

Автопрогін використовує тимчасові тестові позиції для окремої перевірки кожного етапу кампанії. Окремий driving replay фізично проходить першу доставку через п'ять дорожніх точок без телепортації після початкового тестового розміщення. Запускай тести з окремим `XDG_DATA_HOME` під `/tmp`, щоб не змінити свій прогрес.
