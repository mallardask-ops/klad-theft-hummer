# Коростишів: карта першого епізоду

Місто збирається `KCity.build()`. Осі п’яти вулиць: -160, -80, 0, 80, 160 м. Проїжджа частина 16 м, триметрові тротуари, бордюри, розмітка переходів і центральних смуг. Стартова зона біля кафе має широке місце перед фасадом, щоб завдання й перша машина залишались видимими.

П’яти- та триповерхівки мають панельні шви, вікна, балкони, двері, навіси, технічні шахти й пласкі дахи. Квартали чергують житлові будинки, цегляні магазини, гаражі, дерева, лавки, урни та дворові гойдалки. Написи намальовані кирилицею; фактури бетону, старої цегли, шиферу, іржі та деревини мають розмір 64 × 64. Найближча фільтрація, матові поверхні й семигранні дерева задають вигляд міської гри початку 2000-х. Це авторська карта, а не точне відтворення географії міста.

Вікна і вивіски об’єднуються за матеріалами в сітки; повторювана геометрія використовує MultiMesh. Основна архітектура і земля мають статичні колізії; дрібна вулична деталь не перешкоджає їзді. `map_blocks` повертає фактичні прямокутники будівель для радара, `pedestrian_spawns` дає позиції тротуарів, `get_district()` називає зону.

Джерело текстур: власна детермінована генерація `tools/build_textures.py` через Pillow, зерно 1974. Написи: встановлений DejaVu Sans Condensed (вільна ліцензія DejaVu; гарнітура використовується лише для растрування вивісок). Усі геометричні форми та композиція міста створені в коді цього проєкту. Жодного оригінального ресурсу GTA не використано.

## Перевірка поточної збірки

Godot 4.7.2: окрема headless-сцена створила 125 споруд і 125 прямокутників радара, 60 точок пішоходів, 144 колізійні форми та 58 вузлів геометрії. Пам’ятник на площі використовує Blender-модель `assets/models/stone_monument.glb`.

До всіх шести сюжетних точок прокладено видимі заїзди з розривами бордюрів. На західній межі лісопилки відкриті ворота шириною 16 м. Перевірено 167 положень автомобільного паралелепіпеда 2.6 × 1.4 × 5 м через `PhysicsDirectSpaceState3D.intersect_shape`; зіткнень з архітектурою немає. Це перевірка геометричної прохідності, а не заміна керування реальним автомобілем.

Графічно перевірено окремі ракурси кафе, площі й кар’єру; останній запуск закінчився без помилок Godot. Атмосферне освітлення та туман задає основна сцена гри.

`road_route(from, to)` повертає масив скінченних `Vector3` з початковою та кінцевою точками, без послідовних дублікатів. Маршрут знаходиться через зважений граф 25 перехресть та проєкції на найближчі дороги. Для шести сюжетних дворів використовуються відкриті заїзди; вихід із двору проходить тим самим коридором. Усередині одного відкритого двору маршрут прямий. Функція працює без NavigationServer; для довільного двору без заданого заїзду остання ділянка веде від найближчої дороги до цілі.

Повторна перевірка навігації: 1 225 пар старт/ціль, 82 323 автомобільні проби, 0 помилок кінцевих точок, дублікатів чи зіткнень. Однакова початкова й кінцева позиція повертає одну точку; нечислові координати повертають порожній маршрут. Міські растри отримують mipmaps один раз при складанні сцени; найближча фільтрація з mipmaps зберігає дрібні піксельні фактури поблизу та прибирає шум удалині. Після зміни проведено графічний запуск без помилок Godot.
