# Задачі для слабших моделей (Grok 4.7 і подібні)

Тут лише текстова й структурна робота. Візуалу, 3D, шейдерів і правок у `scripts/` немає.

Кожна задача:
- самодостатня;
- має вхідні файли, вихідний файл і точний формат;
- перевіряється скриптом або простим читанням.

Задачі незалежні, тож їх можна роздати різним моделям паралельно.

## Загальні правила (дай їх моделі разом із задачею)
1. **Нічого не вигадувати.** Усі тексти реплік копіюються з джерел дослівно, з тими самими словами, лайкою й русизмами в мові персонажів. Якщо чогось нема в джерелі, залишай поле порожнім (`null`) і пиши це в кінці звіту.
2. **Пріоритет джерел:** `docs/story/CANON.md` > `docs/story/missions/*.md` > `docs/story/act*.md` > решта. Якщо джерела суперечать одне одному, обирай за цим порядком і запиши суперечність.
3. **Змінюй тільки свій вихідний файл.** Інші файли не чіпай, навіть якщо бачиш помилку: опиши її у звіті.
4. Мова вихідних текстів українська. Ключі JSON і `id` латиницею, `snake_case`.
5. Наприкінці роботи дай звіт до 15 рядків: що зроблено, що пропущено, які суперечності знайдено.
6. **Для задач 10–18:** читай тільки зазначені розділи джерел і `CANON.md`. Вони не залежать від результатів задач 1–9. Для кожного запису таблиці й кожної нагороди заповнюй `source` або передбачене форматом поле `*_source` у форматі `шлях/до/файлу.md:рядок`; за потреби додавай `sources` зі списком посилань на інші місця джерела.
7. **Для задач 10–18:** текстові поля копіюй з джерела, прибираючи лише Markdown-обрамлення. Числа можна переводити в зазначені одиниці (наприклад, `2:30` у 150 секунд). Невідомі значення залишай `null`; порожній список використовуй лише там, де справді немає елементів. Координати, баланс, нові назви й умови не вигадуй.
8. **Для задач 10–18:** JSON нижче показує структуру одного запису. Заміни шаблонні `null` відомими значеннями й перенеси всі записи зі свого розділу. Це підготовка даних; підключати їх до гри або змінювати валідатори не потрібно.

## Задача 1. Місії Акту I в JSON
**Навіщо:** це дані, з яких гра будуватиме місії. Зараз у грі 4 місії в `data/missions.json`, а сюжет має 71.

**Вхід:** `docs/story/missions/act1_prologue_edik.md`, `act1_tolik_taras.md`, `act1_kiber_vadymovych_valya.md`, `docs/story/CANON.md` (порядок відкриття), `docs/story/places.md`.

**Вихід:** `data/story/missions_act1.json`.

**Формат:**
```json
{
  "act": 1,
  "locations": {
    "home_khomenko": {"name": "Хата Хоменків", "district": "ПРИВАТНИЙ СЕКТОР", "note": "сховка 1"}
  },
  "missions": [
    {
      "code": "Е-1",
      "id": "coffee_run",
      "title": "ЙОБНЄМ КАВИ",
      "giver": "Едік",
      "start": "cafe",
      "unlock_after": ["П-2"],
      "unlocks": ["Е-2", "К-1", "В-1"],
      "time": "21:00",
      "reward": 350,
      "reward_items": ["кава"],
      "cutscenes": [
        {"name": "назва катсцени", "when": "intro",
         "setting": "ремарка про місце й світло одним реченням",
         "lines": [
           {"speaker": "Едік", "text": "точна репліка без лапок-ялинок довкола", "direction": "ремарка в дужках, якщо є, або null"}
         ]}
      ],
      "steps": [
        {"type": "drive", "label": "Їдь до гаражів.", "position": "garages", "radius": 12, "vehicle": true}
      ],
      "fail": ["що провалює місію, коротко"],
      "in_mission_lines": [
        {"speaker": "Кібер", "text": "точна репліка", "trigger": "коли звучить"}
      ],
      "outro_changes": ["що змінюється у світі після місії, коротко"]
    }
  ]
}
```

**Правила полів:**
- `code` — код місії з файлу (П-1, Е-1, БВ-4…). `id` — англійська назва в `snake_case`. Для чотирьох наявних місій бери id з `data/missions.json`: `coffee_run`, `salty_gold`, `foreign_box`, `my_turn`. Перевір фактичні id у тому файлі.
- `start` і `position`: це або наявний ключ (`cafe`, `plaza`, `market`, `garages`, `sawmill`, `quarry`, `dorm`), або новий ключ, описаний у `locations`. Для автозапуску пиши `"start": "auto"`. Крок без місця (катсцена посеред місії) отримує `"type": "cutscene"`, тоді `position` не потрібен.
- `type` кроку — тільки одне з: `drive pickup talk combat escape chase timer stealth defend escort photo drone choice cutscene`. Тип бери з тексту місії, де він зазвичай указаний.
- `label` — коротка ціль для HUD, як у GTA III, наказовий спосіб, **до 70 символів**. Це єдине поле, яке можна формулювати своїми словами.
- Додаткові поля кроку, якщо є в тексті: `radius`, `vehicle`, `enemies`, `faction`, `item`, `timer_sec`, `wanted_level`, `options` (для `choice`).
- Репліки: кожна `> **Ім'я:** текст` з катсцен стає об'єктом у `lines`. Ремарку в дужках *(…)* винеси в `direction`, з тексту прибери.
- Рядки на кшталт «*Подро мовчить*» і ремарки камери в `lines` не потрапляють. Перше речення першої ремарки сцени йде в `setting`.

**Перевірка (обов'язково, до здачі):**
```bash
python3 -I tools/story/validate_story_data.py data/story/missions_act1.json
```
Здавай тільки з **0 помилок**. Помилка «текст не знайдено в джерелах дослівно» означає, що репліку переписано, а не скопійовано. Попередження про `unlock_after` з іншого акту — нормально.
