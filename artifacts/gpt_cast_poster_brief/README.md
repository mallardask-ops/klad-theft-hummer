# Великий Кладій Закладок: постери й лого

Фінальні файли з новою назвою:

- [Горизонтальний постер, 1536×1024](../../assets/ui/cast_poster.png)
- [Вертикальна обкладинка, 1024×1536](../../assets/ui/cast_poster_tall.png)
- [Окреме прозоре лого PNG](../../assets/ui/game_logo.png)

Напис точно за запитом автора: **Великий Кладій Закладок**, три рядки, біла заливка та товстий чорний контур у стилі GTA. Лого розміщено внизу на центральній куртці Подро.

[Горизонтальний оригінал без тексту](../../assets/ui/cast_poster_notext.png), [вертикальний оригінал без тексту](../../assets/ui/cast_poster_tall_notext.png), [аркуш персонажів](character_sheet.png).

У двох форматах той самий склад із 12 основних персонажів. Зовнішнє тло біле; натовп, чорнильні контури, хустка й золота банка походять із брифу. Брат і Кащєй пропущені як необов'язкові пасхалки.

Створено й відредаговано вбудованим imagegen. ImageMagick використано тільки для технічного приведення зовнішнього майже білого тла постерів до #FFFFFF. Вихідні растри в generated_native/, проміжні варіанти в superseded/.
