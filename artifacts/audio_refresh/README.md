# Оновлення аудіо

31 асет із CC0-джерел замінили синтезовані залишки й частину невдалих Foley. Джерела та автори: [audio-sources.md](../../docs/audio-sources.md). Оригінали, ліцензії, параметри обрізання і SHA-256: [manifest.json](../../assets/audio/recorded/manifest.json).

Зміни в грі:

- Записані бензиновий та дизельний мотори: окремо холостий хід і навантаження, плавні зміни гучності та обертів.
- Шум дороги, шини при гальмуванні й різні удари для слабкого/сильного зіткнення.
- Окремі удари по людині й по металу. Початкову тишу в помасі молотка скорочено з 239 до 4 мс; затримку дверей — зі 112 до 4 мс.
- Короткі записані клацання меню, монета для підбору, скретчі та музичний сигнал місії.
- Повний 66-секундний фанк-трек Joth для радіо; старий восьмисекундний WAV та залишковий імпорт прибрано.
- Просторові удари, сирена й найближчий автомобіль у русі. Мікс містить SFX, UI, Vehicle, Environment, Music, регулятор Game та лімітер Master до −1 dB.
- Пауза глушить звуки світу; гучність 0 дає повну тишу. Сигнал місії має власний плеєр і тимчасово приглушує радіо.

[Приклад міксу](audio-preview.mp3) містить 19,5 с аудіо, записаного з гри. [Послідовність фрагментів](audio-preview-timeline.json). Це нарізка запису Master після загальної гучності та лімітера, без додаткового вирівнювання чи накладання ефектів.

## Перевірка

[Чистий аудіопрогін](validation/audio-replay-clean.log) пройшов 13 сценаріїв. [Вимірювання](validation/mix-check-clean.json) перевіряє встановлені файли, хеші оригіналів, рівні PCM, початок ефектів і записані фази. Пік у щільному міксі −1 dB без семплів повної шкали; пауза й mute мають пік 0; сирена праворуч дає правий канал на 2,31 dB голосніше.

Імпорт, headless smoke та експорт перевіряються через [validate_audio_release.py](../../tools/validate_audio_release.py). Актуальний результат експорту: [latest-release.json](validation/latest-release.json). Кожен запуск має окремий receipt і сирі журнали; невдалі спроби збережено. Linux-команди замінюють PowerShell-скрипт навички, оскільки PowerShell на цій машині відсутній. Збереження та налаштування тестів ізольовані в `/tmp`.

Перевірено програмний мікс Godot з драйвером Dummy, графічний запуск та відтворення вводу. Прослуховування через фізичні динаміки не виконувалось. Записи є художніми аналогами, а не файлами GTA III чи документальними записами місцевих машин і міста.

```sh
python3 tools/import_recorded_audio.py
python3 tools/build_audio.py
godot --path . --audio-driver Dummy --script res://tools/audio_replay.gd -- --evidence-dir=res://artifacts/audio_refresh/validation/replay-manual
python3 tools/check_audio.py --replay-dir artifacts/audio_refresh/validation/replay-manual --output artifacts/audio_refresh/validation/mix-manual.json
python3 tools/validate_audio_release.py
```

[Попередні звуки й код](before/) збережено для порівняння. Генератор `tools/build_audio.py` тепер лише перевіряє й копіює імпортовані файли; відсутній запис зупиняє збірку.
